Quick guide, mobile access & beta limits
  1. Import a beat and set its BPM. Use grid start if it has silence before the first beat.
  2. Choose your voice preset and the song key. Start with Clean rap or Singing; Grim abyss is intentionally extreme.
  3. Enable the mic, allow permission, and use wired headphones. Hear live effects can add audible latency.
  4. Choose A and B, turn on Loop recording and Metronome, then record. Stop, audition your takes, and insert the best one.
  5. Set clip start times or nudge vocals. Preview Rap on beat corrections before keeping them.
  6. Analyze & balance, listen to the final mix, save the project and export.

On iPhone, iPad or Android, open this HTTPS page directly in Safari or Chrome, then use Add to Home Screen for an app-like window. Files are imported from your device and audio is processed here. Local controls do not upload audio. Infected Mixer sends vocals and beat to RoEx only after you confirm. A downloaded Windows folder does not run on a phone. Internet is required for sign-in and access checks. The Windows app shares this Studio and loads updates when reopened.

Desktop private projects are not converted here. WAV or other browser-decodable vocals can be imported. Real hardware latency, background recording and Bluetooth behavior vary by device. Keep this page foregrounded while recording; a hidden page stops capture to protect your takes.

Live tuning uses monophonic pitch estimation and granular pitch shifting. Distorted audio, chords and noisy recordings can confuse it. Key estimates need ear checking. Pocket uses BPM, key, style, grid, swing, sensitivity and transient protection to make a best-effort timing correction; no algorithm can guarantee perfect placement for every performance. Master styles provide repeatable render settings and peak protection, not a guarantee of commercial mastering.
